# Equipment Downtime Response Procedure

Document ID: SOP-MAINT-001
Department: Manufacturing Operations
Category: Equipment Maintenance
Version: 1.0

## Purpose

This procedure describes the initial response to unplanned equipment
downtime on a manufacturing production line.

## Initial Assessment

When equipment stops unexpectedly, the operator must record the
equipment identifier, fault code, timestamp, affected production line,
and any displayed error message.

Operators must not bypass safety interlocks or attempt repairs outside
their authorization.

## Escalation

If the equipment cannot be restored using an approved operating
procedure, the operator must notify the maintenance team.

If a safety hazard is suspected, the affected equipment must remain
in a safe state and the site emergency or safety procedure must be
followed.

## Documentation

Every downtime event must include:

- Equipment identifier
- Start timestamp
- Reported fault code
- Description of the observed problem
- Actions already attempted
- Escalation status

## Resolution

Only authorized personnel may perform maintenance requiring technical
intervention.

The incident record must include the resolution, restoration timestamp,
and any follow-up actions.
